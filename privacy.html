시행일: 2026년 11월 26일

1. 수집하는 개인정보 항목

「도트 건물주」는 회원가입, 로그인, 외부 서버 통신 기능을 제공하지 않으며, 어떠한 개인정보도 수집하거나 외부 서버로 전송·저장하지 않습니다.

  • 이름, 이메일, 전화번호, 위치정보, 기기 식별자(ADID 등), 결제 정보 등을 수집하지 않습니다.
  • 제3자 분석(Analytics) SDK 및 광고 SDK를 포함하지 않습니다.

2. 게임 데이터의 기기 내 저장 및 백업

게임 진행 데이터(보유 게임 재화, 작물, 건물, 설정 등)는 오직 사용자 기기 내부 저장소(localStorage)에만 저장되며 개발자나 제3자가 열람할 수 없습니다.

  • 세이브 코드 복사/불러오기: 사용자가 직접 설정 화면에서 백업 버튼을 누를 때만 기기 클립보드에 텍스트를 쓰거나 붙여넣은 코드를 읽어 로컬 저장소를 복원합니다.
  • 데이터 삭제: 게임 내 [설정 → 세이브 지우고 처음부터] 또는 기기의 앱 데이터 삭제·앱 제거를 통해 모든 로컬 데이터를 즉시 삭제할 수 있습니다.

3. 제3자 제공 및 처리 위탁

수집하는 개인정보가 없으므로 개인정보를 제3자에게 제공하거나 처리를 위탁하지 않습니다.

4. 아동의 개인정보 보호

본 앱은 개인정보를 일체 수집하지 않으며, 연령과 무관하게 어떤 이용자의 개인정보도 서버에 기록하지 않습니다.

5. 개인정보처리방침 변경 및 문의처

본 방침의 내용이 변경되는 경우 앱 업데이트 또는 이 페이지를 통해 공지합니다.
